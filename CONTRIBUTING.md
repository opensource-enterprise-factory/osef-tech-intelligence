# Contributing to OSEF Tech Intelligence

Thanks for strengthening reliable Open Source intelligence for Francophone Africa.

## Editorial submission

1. Select the appropriate stream and create a descriptive Markdown file using `YYYY-MM-DD-short-title.md`.
2. Use [templates/veille.md](templates/veille.md).
3. Link to original vendor/foundation/project announcements. State publication date, relevant event date and date verified.
4. Explain why the development matters, identify risks or limits, and suggest **one achievable action** (lab, issue, contribution, meetup, training or partnership).
5. Check for duplicate reports across all three streams.
6. Submit a Pull Request with sources, verification notes and any uncertainty explicitly stated.

## LinkedIn

- Draft with [templates/linkedin-post.md](templates/linkedin-post.md) under `linkedin/drafts/`.
- Distinguish opinions from facts and link to authoritative sources.
- Approval and actual publication are **separate** steps.
- Move to `linkedin/published/` only after the URL and publication date are verified.

## Pull Request checklist

- [ ] At least one working primary-source link.
- [ ] Dates and claims verified.
- [ ] No duplicate news item without a material update.
- [ ] Francophone Africa relevance and action clearly described.
- [ ] Attribution and permissions for media/assets checked.
- [ ] No secrets, customer data, or unsupported commercial claim.
- [ ] Publication status correctly labeled.

## Suggested team

- Researcher / curator: identifies leads
- Technical reviewer: validates technical facts
- Editorial reviewer: validates clarity and relevance
- Page administrator: explicitly approves external publishing

An individual may cover multiple functions, but avoid self-approving sensitive publications when possible.
