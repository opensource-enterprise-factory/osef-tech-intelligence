## Faits vérifiés et contexte
SDK stables 3.0.0, API 1.10.0, Node.js >=22.15.0 ; modifications incompatibles et consolidation des signaux.

## 1. Ce qui change
Migration majeure depuis les SDK 2.x, avec changements d'API et de packages.

## 2. Intérêt pour l’Afrique francophone
Auditer les API Node.js des entreprises et plateformes de paiement ; tester les dépendances avant mise à jour.

## Impact opérationnel
Valider les prérequis, mesurer les résultats en laboratoire et documenter les limites avant une décision de production.

## 3. Action OSEF
Guide de migration 2.x vers 3.x, matrice de compatibilité et recette.

## 4. Lab à construire
LAB-OTEL-003 : API Node.js instrumentée, Collector et backend OTLP ; relever traces, métriques et logs sous 2.x, migrer, comparer. Succès : trois signaux collectés et tests applicatifs passants.

## 5. Meetup afférent
OpenTelemetry 3.0 : vos applications Node.js sont-elles prêtes ? Public DevOps/SRE/développeurs ; démo de migration de 45 min.

## Opportunités de contribution open source
Tester les incompatibilités et proposer issues/PR documentaires.
