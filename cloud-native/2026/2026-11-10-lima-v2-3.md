## Faits vérifiés et contexte
Lima v2.3 introduit un pilote expérimental HCS sous Windows, des réseaux VM gérés sous Linux et une interface terminal ; restrictions du pilote Windows à vérifier.

## 1. Ce qui change
Extension des possibilités de VM locales, notamment sous Windows sans QEMU dans le mode HCS expérimental.

## 2. Intérêt pour l’Afrique francophone
Évaluer une option de lab sur postes personnels, sans présumer de compatibilité ou performances supérieures à VirtualBox.

## Impact opérationnel
Valider les prérequis, mesurer les résultats en laboratoire et documenter les limites avant une décision de production.

## 3. Action OSEF
Guide d'installation et matrice de compatibilité Lima/VirtualBox/WSL2.

## 4. Lab à construire
LAB-DEV-006 : Windows ou Linux compatible, Lima v2.3 ; installer, créer une VM, tester SSH, réseau, arrêt et redémarrage. Succès : VM reproductible et limites documentées.

## 5. Meetup afférent
Lima : alternative à VirtualBox pour les labs ? Public DevOps/étudiants ; démonstration 45 min.

## Opportunités de contribution open source
