# Proposition de post LinkedIn — OSEF

**Kubernetes en production : votre cluster est-il prêt… mais vos applications le sont-elles ?**

Le 27 octobre 2026, la communauté Kubernetes a annoncé un nouveau **Workload Conformance Working Group**.

L'objectif : travailler à un standard commun pour les comportements des applications exécutées sur Kubernetes, en associant développeurs et opérateurs.

Pour les équipes IT en Afrique francophone, la question est très concrète : **que devient votre application lorsqu'un nœud est drainé ou que le cluster est mis à jour ?**

Chez **Open Source Enterprise Factory (OSEF)**, nous proposons d'en faire un laboratoire reproductible : tester les interruptions, observer la résilience applicative et documenter les résultats.

**Un cluster fonctionnel ne suffit pas ; les workloads doivent aussi être préparés à l'exploitation.**
